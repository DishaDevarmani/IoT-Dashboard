# IoT Dashboard — ESP32 + MQTT + Web UI

A real-time sensor dashboard built with ESP32, DHT22, MQ135, MQTT, and a live web frontend
## Tech Stack
- ESP32-WROOM-32 (WiFi + sensor node)
- DHT22 (Temperature & Humidity)
- MQ135 (Air Quality)
- MQTT (Mosquitto / HiveMQ Cloud)
- HTML + MQTT.js + Chart.js (Dashboard)
- KiCad (PCB Design)

## Folder Structure
- `firmware/` — ESP32 Arduino code
- `dashboard/` — Web UI files
- `pcb/` — KiCad schematic and layout files
